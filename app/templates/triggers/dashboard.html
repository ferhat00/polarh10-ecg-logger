How to read this

  • Model. One negative-binomial rate model per tag: confirmed ectopic count per session, offset by log analysed hours, with a sin/cos hour-of-day pair (ectopy has a circadian rhythm — so do most exposures) and, when the data supports it, the activity group. {% for note in analysis.model_notes %}
    {{ note }}{% endfor %}
  • Variability context. Ectopic burden swings severalfold between days within the same person (hour-to-hour variation near 50% was reported as far back as Morganroth 1978, and a two-day comparison needs a >83% change to beat noise). Wide intervals here are honesty, not weakness; a rate ratio only firms up as tagged and untagged sessions accumulate over weeks.
  • Multiple tags. Each tag is tested separately; testing many tags means some intervals will exclude 1.0 by luck alone. Treat a single interesting row as a hypothesis to keep testing, not a finding.
  • Tags are self-reported and sessions are not randomized, so an association can come from anything that travels with the tag (time of day, activity, sleep…). For a stronger design, assign yourself exposure blocks in advance — e.g. caffeine on/off in 2-day blocks, as the published trigger trials do — and tag accordingly.
